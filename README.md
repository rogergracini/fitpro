# FitPro - Sistema de Gestão para Personal Trainers

Sistema desenvolvido com **React + Vite** para gestão de alunos, treinos e agendamentos. Projeto focado em performance e arquitetura desacoplada.

## 🛠️ Tecnologias
- **Frontend:** React 18, Tailwind CSS, Lucide React.
- **UI Components:** Shadcn/UI (Radix UI).
- **Gerenciamento de Estado:** TanStack Query (React Query).
- **Arquitetura:** Mock API Engine com suporte a LocalStorage para persistência offline.

## 🚀 Como rodar o projeto
1. Clone o repositório: `git clone https://github.com/rogergracini/fitpro.git`
2. Instale as dependências: `npm install`
3. Inicie o ambiente de desenvolvimento: `npm run dev`
4. Acesse: `http://localhost:5173`
